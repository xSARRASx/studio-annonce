ÉVÉNEMENTS DATA LAYER

page_view_spa
  Navigation interne réelle ; page_path, page_location et page_referrer sans
  paramètres de requête ni fragments libres. support : site ou app.
  La balise de configuration GA4 doit assurer la première page vue.
  Ne pas doubler ce signal avec le suivi automatique des changements d'historique.

demo_interaction
  Première interaction par élément et session sur les pages publiques.
  element : comparateur / film / parcours / filtre. variante facultative.
  Les manipulations dans le studio connecté ou la démo locale sont exclues.

inscription_code_envoye
  Après réponse positive à la demande de code d'une inscription.
  Un renvoi du code n'ajoute pas un autre événement dans la même session.

compte_cree
  Après vérification réussie de l'email d'un NOUVEAU compte.
  methode : email ; support ; value : 0 ; currency : EUR.
  Une connexion, un mot de passe oublié ou un retour d'un client n'est pas
  une création de compte. L'API renvoie nouveau_compte=true uniquement ici.

login
  Connexion email / mot de passe d'un compte existant ; method : email ; support.
  Signal secondaire, pas une nouvelle inscription.

photo_importee
  Envoi réellement confirmé par l'API, avec nb_photos=1 et format de l'image.
  Chaque fichier du lot a sa confirmation ; répéter le même envoi ne le recompte
  pas. Aucun événement à la simple sélection d'un fichier ni dans la démo locale.
  premiere_importation n'est pas deviné : ce champ facultatif est omis.

generation_terminee
  Résultat IA réel confirmé, ou erreur du moteur.
  generation_id stable pour le résultat ; outil : retouche ou photos_video ;
  reussie ; correction ; support.
  Les vidéos en attente/en cours ne déclenchent pas cet événement.
  Réouvrir un ancien résultat terminé ne le recompte pas.
  Une erreur de solde, un refus de validation ou un quota atteint n'est pas
  traité comme un échec de génération IA.
  Une erreur de retouche sans version produite possède un UUID de tentative.
  Les préparations de brief sans génération ne sont pas comptées comme résultats.

telechargement_hd
  Premier téléchargement effectivement acquis, confirmé par les en-têtes API.
  photo_id ; type_telechargement : offerte ou credit ; outil : retouche ; support.
  Aucun revenu associé. Re-télécharger la même photo ne recompte pas.

begin_checkout
  Session Stripe créée, juste avant ouverture du paiement sécurisé.
  commande_id = identifiant de commande interne ; value = montant TTC du panier,
  calculé avec le catalogue du serveur ; currency : EUR ; pack ; type_pack ;
  nb_credits ; items (item_id, quantity) ; support.
  200 ms maximum avant redirection ; l'échec du suivi ne bloque jamais Stripe.

pack_achete
  Achat réel confirmé en base par le paiement existant, et crédits attribués.
  transaction_id = même commande_id que begin_checkout.
  value ET montant_ttc : montant réellement payé en euros ; currency : EUR.
  valeur_base : ca_ttc ; pack ; type_pack ; nb_credits ; premier_achat ; items ;
  support ; user_data facultatif.
  Une commande test, en attente, remboursée ou d'un autre compte est exclue.
  Réservation côté serveur, garde de session et accusé empêchent les doublons.
  Le paramètre ?achat= de l'URL seul ne suffit JAMAIS à valider un achat.
  Le retour Stripe reste /app/compte/?achat=... et les webhooks sont conservés.

Les créations des administrateurs et du propriétaire sont exclues du suivi
commercial ; leurs générations restent gratuites dans le produit.

CONVERSIONS AMÉLIORÉES — NE PAS ENVOYER L'EMAIL À GA4

Pour compte_cree et pack_achete uniquement, un email normalisé peut se trouver
dans user_data.email_address, après accord. Le tag Google Ads doit appliquer
le hachage pris en charge par Google, avec ad_user_data=granted.
Les événements suivants remettent user_data à null pour éviter la propagation.
Pas d'adresse, pays, téléphone ou nom inventé. Pas d'email en paramètre GA4.
Photos, prompts, codes, mots de passe, clés API et jetons restent exclus.
Configurer explicitement les paramètres GA4 ; ne pas envoyer tout le dataLayer.

VALEUR DES ACHATS : CHIFFRE D'AFFAIRES TTC

La formule TVA 20 % et frais Stripe Hong Kong 5,9 % + 0,26 € du guide n'est pas
appliquée sans confirmation de la fiscalité et du contrat Stripe effectif.
La valeur envoyée est donc le TTC réel, pas une marge estimée.
Les frais fournisseurs réels ont leur registre séparé dans l'administration.
Adapter les objectifs et rapports Google à valeur_base=ca_ttc ; ne pas nommer
cette valeur « bénéfice » ou « montant net ».
